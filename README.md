# RE-DEFEND AI — Real-Time 3D Cyber-Physical Stress Engine

> **Note for Hackathon Evaluators & Judges:**  
> This repository contains the **interactive prototype & Proof-of-Concept (PoC)** built specifically for the hackathon demonstration to validate core 3D WebGL rendering, physics-based fault rules, dynamic SCADA intrusion isolation, and cascade vulnerability scoring.  
> **Production Status:** The full-scale enterprise engine featuring live SCADA/IoT ingestion, automated microgrid switching APIs, and multi-city GIS scaling is currently in active development.

---

##  Overview
**RE-DEFEND AI** is a geospatial 3D Cyber-Physical System (CPS) visualization and predictive stress-testing engine focused on urban grid resilience across Pune Metropolitan Region. It models multi-sector cascading infrastructure failures across power substations, water treatment plants, transit corridors, and critical emergency healthcare routes under compound climate and cyber threats.

---

## Key Features & Capabilities

- **Geospatial 3D WebGL Layer:** Interactive Three.js + MapLibre GL 3D visualization using Carto Dark Matter styling with real-time dynamic camera controls.
- **Cascade Simulation Engine:** Physics-informed stress calculations mapping dependencies between MSEDCL high-voltage substations, Parvati/Lashkar water pumping works, and critical care centers (Sassoon, Deenanath Mangeshkar, Ruby Hall).
- **Prescriptive AI Fortification:** Real-time automated defense protocols including autonomous microgrid islanding, SCADA feeder isolation, and dynamic ambulance vector rerouting around submerged transit underpasses.
- **DEFCON Telemetry HUD:** Real-time visual telemetry, sector health breakdown, Cascade Vulnerability Index (CVI) metrics, and system fault logs.

---

##  Tech Stack

- **Frontend & 3D Visuals:** HTML5, Tailwind CSS, MapLibre GL JS, Three.js (r128)
- **Engine Logic:** Modern ES6 JavaScript (Modular Object-Oriented Design)
- **Simulation Scripts:** Python 3 (Folium, Network/Grid modeling scripts)
